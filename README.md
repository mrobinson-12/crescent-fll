# FLL Code 2026

This is FIRST LEGO League BIOGLOW challenge founder edition code for our team 2026. It does most missions at over 80% accuracy and can get 330 points. This is being submitted to crescent and is based on a template I made myself based on the original template by Skip Morrow.

The main goal of this project was to make our robot's programs:

- Reliable
- Easy to run
- Accurate (pybricks somehow helps)
- More fun to make!

!! THis code is intended to be modified if you want to use it as inspiration !!
We have a custom robot meaning it likely will not work on yours without modification, so you can't just copy our code. 

Instead of having our code all in one file, we have them in different files and a master file to combine so we can individually edit each run. This is easier for debugging and readability.

To use the repo you can install everything with the install scripts in the repo, and then VS Code should recommend you the plugins to install. 

Feel free to use this as inspiration!

Good luck with your season! 🤖
